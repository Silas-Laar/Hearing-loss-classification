# Audiology
Developed an end-to-end machine-learning pipeline for six-class hearing-loss classification using clinically informed audiometric features, SMOTE-balanced stratified validation, seven classifiers, and SHAP-based interpretability across 992 audiograms. Achieved 94.97% test accuracy and 95.39% macro-F1 with XGBoost for six-class classification, while high-frequency (4–8 kHz) features enabled 95.98% accuracy and 95.85% macro-F1 for early hearing-loss detection.
